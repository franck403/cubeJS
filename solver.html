COMMENT ÉCRIRE TON SOLVER

1. Onglet solver.js: tu définis   function solve(cube, ctx)
   et tu retournes les moves: "R U R' F2"  ou  ["R","U","R'","F2"].
2. Ctrl+Entrée: le code est compilé dans 4 Web Workers (l'UI ne gèle jamais),
   puis N cubes sont résolus en parallèle et chaque solution est re-vérifiée
   par un cube de référence indépendant dans la page (pas par ton code).
3. Un solver qui boucle à l'infini est tué au bout de timeout×1.5 et compte comme échec.

cube (voir onglet core.js)
  cube.move("R")  cube.moves("R U R'")   applique en place (renvoie cube)
  cube.clone()  cube.isSolved()  cube.equals(o)  cube.toFacelets()
  cube.twist()  cube.flip()  cube.sliceMask()
  cube.cp cube.co cube.ep cube.eo        état brut (coins/arêtes: position + orientation)
  Cube.MOVE_NAMES[0..17]   Cube.MV[i]   Cube.parseMoves("R U")   Cube.invert("R U")

ctx
  Pas de longueur cible: le harness veut toujours le nombre de moves le plus court trouvé
  avant le timeout. Retourne ta meilleure solution même si le temps est bientôt écoulé.
  ctx.tick()      à mettre dans les boucles chaudes: lève "timeout" quand le temps est écoulé
  ctx.timeLeft()  ms restantes      ctx.timeUp()  bool
  ctx.log("...")  texte affiché dans le panneau Log (bouton Résoudre)

Optionnel
  function init(ctx) { ... }   exécuté une seule fois par worker (tables, précalculs)

Index des moves: face*3 + k, faces U R F D L B (0..5), k = 0 (x)  1 (x2)  2 (x')

Conseils pour tes essais
  - Mode "Scramble" + longueur 4-6 pour déboguer un solver simple.
  - Augmente le timeout pour comparer qualité (longueur moyenne) vs vitesse.
  - Clic sur une ligne rouge des résultats = recharge ce cube pour le résoudre à la main.
  - Le code est gardé dans le navigateur (sauvegarde auto); "Télécharger .js" pour l'exporter.
